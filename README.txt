AMAZON PROFIT CALCULATOR — ON-GST PURCHASE

This PWA mirrors the uploaded Amazon_India_Profit_Calculator_FIXED workbook's
Amazon fee tables and calculation structure, with purchase GST ITC explicitly
shown for the on-GST purchase case.

GitHub Pages:
Upload index.html, manifest.json and sw.js to a public repository root and
publish main/(root). Open the resulting HTTPS URL on Android Chrome and choose
Install app / Add to Home screen.

The Android folder is a WebView wrapper project. Build it in Android Studio to
create an APK.
